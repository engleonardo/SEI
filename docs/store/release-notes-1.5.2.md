# SEI Flow 1.5.2 - novidades

- **Excluir cartão pelo painel**: ícone de lixeira no rodapé do cartão, com confirmação. O cartão vai para a lixeira do Trello.
- **Início e vencimento no diálogo Prazo**: agora é possível editar as duas datas, validar início ≤ vencimento e limpar as datas de uma vez.
- **Sincronização mais rápida em quadros secundários**: o painel carrega somente o quadro selecionado, em vez de buscar todos os cartões vinculados de todos os quadros.
- Na primeira carga, o painel usa direto o quadro padrão, evitando uma busca global desnecessária.
- **Pacote em português (pt_BR)**: locale declarado no manifest, com nome e descrição em português.
- Textos de exclusão mais precisos: o cartão vai para a lixeira do Trello, em vez de “removido permanentemente”.
