# SEI Flow 1.5.3 - novidades

- **Compatível com Firefox 115 ESR**: o mínimo do desktop passou para Firefox 115; o Android continua exigindo 142+.
- **Selo “Atualizado” do SEI** agora limpa quando o processo é aberto, quando o cartão é concluído ou quando você clica no selo (que virou o botão **Marcar processo como lido**).
- **Regra de processo SEI atualizado** usa o estado atual dos cartões, evitando condição de lista desatualizada.
- **Mover para lista + topo**: quando a regra tem as duas ações, o cartão vai para o topo da lista de destino.
- O horário “Atualizado há…” com ícone de relógio continua sendo a última atividade do cartão no Trello.
